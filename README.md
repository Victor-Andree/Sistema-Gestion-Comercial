# Sistema Comercial API

API backend para la gestión de operaciones comerciales, diseñada para administrar ventas, clientes y flujos de ventas de manera eficaz.

## Descripción

Sistema orientado a negocios que requieren control de ventas, registro de operaciones y generación de comprobantes, permitiendo un flujo completo desde ventas pendientes hasta ventas confirmadas.

Desarrollado con una arquitectura escalable que facilita futuras ampliaciones y personalizaciones según las necesidades del cliente.

## Funcionalidades Principales

* Registro de ventas
* Flujo de venta **Pendiente → Completada**
* Gestión de detalle de productos por venta
* Cálculo automático de totales
* Generación de comprobantes
* Asociación de ventas a clientes y usuarios
* Reportes básicos por fecha y estado
* Operaciones seguras por usuario autenticado

## Características Técnicas

* API REST
* Procesos transaccionales
* Estructura preparada para escalabilidad
* Separación clara de responsabilidades
* Base sólida para integración con frontend o sistemas externos
